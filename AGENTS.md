# Instrucciones para Codex y GitHub Copilot
- Proyecto educativo COMIC-CREATOR sin backend, PHP ni base de datos.
- Respetar MVC y módulos ES6; `index.html` permanece en la raíz.
- El paquete `.comicproj` contiene `project.json` y recursos multimedia, nunca rutas absolutas locales.
- Nunca modificar el proyecto actual sin preservar los datos del estudiante.
- Mantener nombres claros en español, UI accesible y estados vacíos en paneles.
- Ejecutar `npm test` antes de entregar modificaciones de lógica.
- No eliminar archivos existentes ni hacer `git push` sin aprobación del usuario.
- Distinguir pruebas automatizadas, pruebas manuales y características pendientes.
